# 🎬 视频去重冲洗工具 (video-rewash) v7.1

基于 **PyQt5 + FFmpeg** 的桌面批量视频"冲洗"工具：对每条视频叠加多维度随机扰动重新编码，
使输出在画面观感基本不变的前提下，与源文件在数据层面产生显著差异，并自动质检输出质量。

> ⚠️ 工具仅提供参数随机化与重编码能力，不保证绕过任何平台的内容识别；
> 实际效果请以自己的固定测试集实测为准。

---

## ✨ 功能特性

### 四维正交去重扰动（每次处理全参数随机）

| 维度 | 手段 |
|---|---|
| **几何** | 缩放推镜（zoompan 动态漂移）、动态微旋（rotate_drift） |
| **色彩** | 亮度 / 对比度 / 饱和度 / 色相微调、通道混色、轻噪点 |
| **时序** | 微变速、重复帧、场景帧扰动、首尾随机裁剪 |
| **音频** | 微变速（与视频同步对齐）、变调、EQ 微调、音画微偏移 |
| **编码域** | CRF / GOP / B帧 / 场景阈值全随机 |

### 流程能力

- **分段处理**：长视频按镜头切分多段，每段独立随机参数，再合并（合并即全新重编码）
- **输出标准化**：10 种比例 × 常用分辨率两级联动、帧率、像素格式、13 种编码器可选
- **体积对齐**：默认按源码率编码，输出体积 ≈ 源体积；源码率与目标不符时自动预转码
- **质量检测**：时长 / 分辨率 / 帧率 / 音轨 / 黑屏等自动校验，问题写入报告
- **指纹报告**：dHash 帧指纹相似度（源 vs 输出），低于阈值视为去重有效
- **批量调度**：目录批量处理、断点续跑（检查点）、失败自动重试、多版本输出
- **成功才落盘**：全程在系统临时目录处理，全部检查通过后才移入输出目录，
  失败不会在输出目录留下任何半成品

### GUI

- 深灰主题、拖放添加文件、路径记忆持久化
- 状态条实时显示环境状态 + 当前预设（激进 / 标准 / 温和 / 自定义）
- 设置三分页：去重参数微调（min/max 网格）/ 流程与输出 / 预设管理（增删导入导出）

## 📁 目录结构

```
video_rewash/
├── main.py / __main__.py   # 入口（python -m video_rewash）
├── core/                   # 编排层：配置、预设、随机快照、处理器、分段、标准化、质检、FFmpeg 执行器
│   ├── processor.py        #   单素材主流水线（探测→快照→处理→质检→指纹→落盘）
│   ├── segment.py          #   镜头切分 + 分段独立处理 + 合并
│   ├── normalize.py        #   输出标准化目标规格
│   └── ffmpeg_runner.py    #   FFmpeg/FFprobe 子进程收口（无黑窗口）
├── video/                  # 视频滤镜链与编码参数（filters.py 含 13 种编码器映射）
├── audio/                  # 音频扰动（变速/变调/EQ/偏移，音画同步）
├── fingerprint/            # dHash 视频指纹相似度检测
├── batch/                  # 批量调度：工作线程、断点检查点、重试、GPU 调度
├── gui/                    # PyQt5 主窗口、设置对话框、样式
├── presets/                # 内置三档预设 + 用户自定义预设
└── logs/                   # 运行日志
```

核心链路：`preset → randomizer（参数快照）→ processor → ffmpeg_runner`，
其余环节（质检 / 指纹 / 预转码）失败不阻断主流程。

## ⚙️ 设置页：流程与输出

### 编码器（13 种，捆绑 FFmpeg 实测全部可用）

| 编码 | 可选后端 |
|---|---|
| H.264 | libx264 / NVIDIA NVENC / Intel QSV / AMD AMF |
| H.265 | libx265 / NVIDIA NVENC / Intel QSV / AMD AMF |
| VP9   | libvpx-vp9 |
| AV1   | libsvtav1 / NVIDIA NVENC / Intel QSV / AMD AMF |

推荐：**N 卡用户选 NVENC 系（最快）**；追求通用兼容选 H.264 (NVIDIA NVENC)。
QSV / AMF 需对应品牌显卡硬件，编码失败时自动回退。

### 比例 → 分辨率（两级联动）

支持 1:1 / 4:5 / 3:4 / 2:3 / 9:16 / 16:9 / 3:2 / 5:4 / 4:3 / 21:9 / 原始比例，
每个比例内置完整常用分辨率档位（如 9:16 含 360×640 … 2160×3840 共 15 档），
切换比例时自动选中像素量最接近的档。

### 画质 / 码率

- `0 = 自动`：体积对齐模式，输出体积 ≈ 源体积
- `填数值`：自行控制画质，值越大画质越好、体积越大（1080p 推荐 2000~4000）

### 像素格式

推荐 **yuv420p**（全平台通用、体积最小）；yuv422p/444p 收益极低且浪费码率。

## 🔄 单素材处理流水线

```
媒体探测 → 体积对齐目标码率（必要时预转码）→ 生成随机参数快照
→ 分段独立处理 或 整文件处理（去重滤镜链 + 标准化折入一遍重编码）
→ 质量检测 → 指纹相似度报告
→ ✅ 全部通过 → 移入输出目录（失败则输出目录无任何文件）
```

性能参考（1080×1920 / 272s 素材，N 卡 NVENC）：不分段约 150s，分段 5 段约 350s。

## ❓ 常见问题

**Q：输出画质差怎么办？**
A：把设置 → 流程与输出 → 画质/码率从「自动」改为具体值（1080p 建议 2000~4000）。
自动模式为对齐源体积会沿用源码率，源码率低则画质上限就低。

**Q：处理中途停止，输出目录里有文件吗？**
A：没有。冲洗成功前文件只存在于系统临时目录，失败/中断不会污染输出目录。

**Q：为什么选不了更高画质又保持体积不变？**
A：体积 = 码率 × 时长，二者只能取其一。要画质就放开体积（码率填值），
要体积对齐就用「自动」。
